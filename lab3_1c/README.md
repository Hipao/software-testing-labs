# Lab 3. Use Case (black-box) testing of the 1C configuration «Учёт ремонтов»

Ручное функциональное тестирование конфигурации 1С «Учёт ремонтов» по пользовательским сценариям (Use Case)
в двух подсистемах: **«Работа с клиентами»** и **«Финансы»**.

## Окружение
- 1С:Предприятие 8.3, учебная версия (8.3.18.1741), Windows 11 64-bit.
- Файловая информационная база, загруженная из `УчетРемонтов.dt` (Конфигуратор → «Загрузить информационную базу»).
- Пользовательский режим: `1cv8t.exe ENTERPRISE /F <каталог базы>`, пользователь без пароля.

## План тестирования
- **Объект:** подсистемы «Работа с клиентами» (Клиенты, Объекты ремонта, Заявка клиента, Смета, Акт выполненных работ,
  Отчёт о ходе выполнения ремонта) и «Финансы» (Статьи движения ДС, Поступление / Расход денежных средств,
  регистр «Денежные средства», отчёт «Движение денежных средств»).
- **Вид:** функциональное тестирование, «чёрный ящик», по сценариям + негативные проверки.
- **Сквозной сценарий:** клиент → объект ремонта → заявка → смета → акт → поступление оплаты → расход поставщику → отчёт ДДС.
- **Критерий прохождения:** фактический результат совпадает с ожидаемым; документы проводятся, данные попадают
  в связанные объекты и отчёты; недопустимые данные отклоняются.
- **Фиксация:** скриншот на каждом ключевом шаге, дефекты — баг-репорты.

## Баг-репорты

| ID | Название | Шаги | Ожидаемый | Фактический | Серьёзность |
|---|---|---|---|---|---|
| BUG_01 | Поле «Телефон» обрезает номер «+7 XXX XXX-XX-XX» | Клиенты → Создать → телефон из 16 символов → Записать | Номер сохраняется полностью | Длина поля 15 символов | Низкая |
| BUG_02 | Неверная «Сумма сметы план» | Смета: работы на 31 300, материалы на 8 000 | 39 300 | 62 600: работы ×2, материалы не учтены; при удалении строки не пересчитывается | Высокая |
| BUG_03 | Заявка не связана со сметой и актом | Создать на основании заявки смету и акт, открыть заявку | Поля «Смета ремонта», «Выполнение заявки» заполнены | Поля пустые | Средняя |
| BUG_04 | Заявка проводится без клиента | Заявка → Создать без клиента → Провести | Ошибка «Поле не заполнено» | Документ проведён | Высокая |
| BUG_05 | Отчёт ДДС без выбора периода | Отчёт ДДС → «Настройки» | Можно задать период | «Не предусмотрено возможности настройки» | Средняя |
| BUG_06 | Поступление с отрицательной суммой | Поступление ДС, сумма −5 000 → Провести | Запрет проведения | Проведено, приход уменьшен | Высокая |

Причина BUG_02 (модуль формы документа «Смета»):

```bsl
Объект.СуммаСметыПлан = Объект.Работы.Итог("СуммаПлан") + Объект.Работы.Итог("СуммаПлан") + Объект.Исполнители.Итог("СтоимостьРаботы");
// второе слагаемое должно быть Объект.Материалы.Итог("СуммаПлан")
```

BUG_04, BUG_06: у реквизитов документов не включена «Проверка заполнения», в обработке проведения нет проверки суммы.
